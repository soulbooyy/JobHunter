# Context Contract — Protected Headless Inputs

> Normative scope revision: **2026-09-24.S3M2-r1**. English is authoritative. This defines required behavior, not implemented or executed acceptance. Earlier scoped consumers remain unchanged.

[Decision register](../../design/contract/sl-03-m2-grill.md) · [Contract index](../index.md)

This body consumes COM-049 and preserved EXR/STO foundations. Frame formats describe JobHunter semantic content, not HTTP bytes or a universal Provider request object.

<a id="ctx-001"></a>
**CTX-001.** **Authority and scope.** ContextPackage MUST identify immutable initial allowed inputs/capabilities/policy; ContextFrame MUST record the Provider-effective semantic input selected for one MODEL Invocation. A Package's possible scope or a provenance claim is not proof that content appeared in a Frame. Semantic role/schema adaptation MUST finish before freezing the Frame; Gateway may only perform semantics-preserving serialization/authentication/protocol adaptation afterward. This M2 profile admits text and function-call messages, schemas/results and required reasoning continuation. Unsupported image/audio/upload/remote-content forms MUST be rejected, not fetched or coerced. Interactive compaction, Memory and business Skill input schemas remain deferred.

Decision sources: [CG06-Q4](../../design/contract/sl-03-m2-grill.md#cg06-q4), [CG06-Q14](../../design/contract/sl-03-m2-grill.md#cg06-q14), [CG06-Q15](../../design/contract/sl-03-m2-grill.md#cg06-q15), [CG06-Q47](../../design/contract/sl-03-m2-grill.md#cg06-q47), [CG06-Q48](../../design/contract/sl-03-m2-grill.md#cg06-q48), [CG06-Q193](../../design/contract/sl-03-m2-grill.md#cg06-q193).

<a id="ctx-002"></a>
**CTX-002.** **Initial Package association.** A semantic Run MUST have exactly one initial Package, published with semantic-start. Its logical retained record has exactly run_id, package_format_key, serialized_payload, byte_length and sha256; the identity is run_id, without Package UUID/revision/current pointer. Compute integrity from the actual deterministic stored bytes. Preserve necessary admitted literals and exact references; do not duplicate all source bodies or non-Frame Provider configuration. Every referenced body actually needed for recovery MUST have an explicit retained-availability agreement.

Decision sources: [CG06-Q5](../../design/contract/sl-03-m2-grill.md#cg06-q5), [CG06-Q14](../../design/contract/sl-03-m2-grill.md#cg06-q14), [CG06-Q47](../../design/contract/sl-03-m2-grill.md#cg06-q47), [CG06-Q188](../../design/contract/sl-03-m2-grill.md#cg06-q188), [CG06-Q200](../../design/contract/sl-03-m2-grill.md#cg06-q200).

<a id="ctx-003"></a>
**CTX-003.** **First Package representation constraints.** The conformance Package format is ContextPackage:Conformance:v1. Its payload has exactly task_input, source_scope, action_scope and context_policy_key. task_input is exactly EVO-022's closed instruction/source_invocation_id object, with its finite consumer-specific admission bounds, not arbitrary messages. source_scope is the closed object {source_invocation_id: UUIDv4} and MUST equal task_input.source_invocation_id; action_scope is an ordered list of closed {action_key: string, projection_protocol_key: string} objects, with unique action_key values. This exercise admits only controlled.response-read.v1 with projection_protocol_key DeepSeekResponseReadProjection:v1; context_policy_key is an immutable controlled code key. References are typed by their actual owner; a source response uses source_invocation_id, with integrity metadata supplied by its retained evidence, never a latest pointer or arbitrary URI. Encode the complete typed payload with COM-045; the format reader MUST consume exactly all bytes and enforce the closed types. A finite max_package_bytes is required before initial publication; over-limit yields PACKAGE_TOO_LARGE with no truncation or partial Run. Other actual Skill consumers define their typed Package payload format before enablement; this is not an open universal source dictionary.

Decision sources: [CG06-Q17](../../design/contract/sl-03-m2-grill.md#cg06-q17), [CG06-Q39](../../design/contract/sl-03-m2-grill.md#cg06-q39), [CG06-Q43](../../design/contract/sl-03-m2-grill.md#cg06-q43), [CG06-Q46](../../design/contract/sl-03-m2-grill.md#cg06-q46), [CG06-Q47](../../design/contract/sl-03-m2-grill.md#cg06-q47), [CG06-Q188](../../design/contract/sl-03-m2-grill.md#cg06-q188), [CG06-Q200](../../design/contract/sl-03-m2-grill.md#cg06-q200), [CG06-Q215](../../design/contract/sl-03-m2-grill.md#cg06-q215).

<a id="ctx-004"></a>
**CTX-004.** **Frame identity and integrity.** A MODEL Invocation has at most one committed Frame. The retained record has exactly invocation_id, frame_format_key, serialized_payload, byte_length and sha256; no Frame UUID, sequence or revision is added. Format derives from the controlled binding. Validate the payload and derive length/hash from actual bytes in the publication boundary; caller-supplied digest claims are not authority. Publish with EXR's semantic intent/reservation boundary. A committed Frame proves frozen intended input, not remote receipt. Invalid or oversized candidates MUST NOT be repaired/truncated into a valid Frame.

Decision sources: [CG06-Q15](../../design/contract/sl-03-m2-grill.md#cg06-q15), [CG06-Q16](../../design/contract/sl-03-m2-grill.md#cg06-q16), [CG06-Q48](../../design/contract/sl-03-m2-grill.md#cg06-q48), [CG06-Q52](../../design/contract/sl-03-m2-grill.md#cg06-q52), [CG06-Q55](../../design/contract/sl-03-m2-grill.md#cg06-q55), [CG06-Q133](../../design/contract/sl-03-m2-grill.md#cg06-q133), [CG06-Q134](../../design/contract/sl-03-m2-grill.md#cg06-q134).

<a id="ctx-005"></a>
**CTX-005.** **Current Frame payload.** ContextFrame:DeepSeekChatCompletions:v1 is COM-045 encoding of exactly messages, tools and provenance. messages is an ordered list of closed alternatives: system/user have role and content (string); assistant has role, content (string or null), reasoning_content (string or null), and tool_calls (ordered list of closed id/name/arguments string objects); tool has role, tool_call_id and content (string). Preserve absent protocol content as null, distinct from empty string; no role, text or argument normalization. tools is an ordered list of closed name, description (string) and parameters (admitted data-only JSON-schema object) definitions. TOL-011 closes the first DeepSeekResponseReadProjection:v1 schema; any later action must publish its own owned exact projection before exposure. Arbitrary SDK objects are forbidden. Actual function-wrapper mapping is deterministic from this format. Gateway consumes only decoded messages/tools plus frozen non-Frame configuration, never provenance as model input. Required reasoning history MUST be preserved in its original exact semantic content; it is not Memory/fact authority or default user-visible output. Q195's current DeepSeek continuation requirements are owned by TOL-014.

Decision sources: [CG06-Q48](../../design/contract/sl-03-m2-grill.md#cg06-q48), [CG06-Q97](../../design/contract/sl-03-m2-grill.md#cg06-q97), [CG06-Q107](../../design/contract/sl-03-m2-grill.md#cg06-q107), [CG06-Q128](../../design/contract/sl-03-m2-grill.md#cg06-q128), [CG06-Q133](../../design/contract/sl-03-m2-grill.md#cg06-q133), [CG06-Q134](../../design/contract/sl-03-m2-grill.md#cg06-q134), [CG06-Q139](../../design/contract/sl-03-m2-grill.md#cg06-q139), [CG06-Q193](../../design/contract/sl-03-m2-grill.md#cg06-q193), [CG06-Q195](../../design/contract/sl-03-m2-grill.md#cg06-q195), [CG06-Q198](../../design/contract/sl-03-m2-grill.md#cg06-q198).

<a id="ctx-006"></a>
**CTX-006.** **Provenance representation.** provenance is an ordered list of closed entries with location, origin and projection_key. location is exactly {kind: MESSAGE, index: integer, field: content | reasoning_content | tool_calls} or {kind: TOOL_SCHEMA, index: integer}. Indexes are zero-based nonnegative exact integers. origin is exactly one tagged object: {kind: SKILL_CONTROL, skill_key: string, execution_config_ref: string}; {kind: TASK_LITERAL, field: string}; {kind: EXACT_RESPONSE, source_invocation_id: UUIDv4}; {kind: MODEL_RESPONSE, invocation_id: UUIDv4}; {kind: TOOL_RESULT, invocation_id: UUIDv4}; or {kind: TOOL_DEFINITION, action_key: string, projection_protocol_key: string}. No omitted/additional members or null values are permitted. Keys are nonempty exact registered strings; TASK_LITERAL.field names an admitted top-level task_input field; MODEL_RESPONSE/TOOL_RESULT IDs identify their respective producing evidence. SKILL_CONTROL keys MUST match the Run binding; source/action origins MUST be within Package scope. projection_key is a nonempty exact immutable registered rule key defining identity/projection/redaction, including its deterministic composition when several entries contribute to one location. Entry order is application order; identical location alone does not authorize overwrite or unrecorded content. Referenced indexes MUST exist and the evidence MUST explain the actual included content. No independent manifest identity/current/revision or generic byte-span system is introduced. Provenance cannot substitute for checking actual messages/tools. Future origin types require their own consumed format, not free-form metadata.

Decision sources: [CG06-Q46](../../design/contract/sl-03-m2-grill.md#cg06-q46), [CG06-Q61](../../design/contract/sl-03-m2-grill.md#cg06-q61), [CG06-Q134](../../design/contract/sl-03-m2-grill.md#cg06-q134), [CG06-Q140](../../design/contract/sl-03-m2-grill.md#cg06-q140), [CG06-Q194](../../design/contract/sl-03-m2-grill.md#cg06-q194), [CG06-Q215](../../design/contract/sl-03-m2-grill.md#cg06-q215).

<a id="ctx-007"></a>
**CTX-007.** **Input preparation.** Before PREPARED, candidate assembly MUST be discardable deterministic local work without remote side effects, dispatch rights, reservation or durable Frame authority. It may perform explicitly authorized exact Application reads, not fabricated ToolInvocations. Crash permits recomputation from authoritative sources. Concurrent candidates confer no priority: PREPARED creation atomically arbitrates the Run's serial position. Required Skill guidance comes from exact static registration/configuration; no filesystem discovery, dynamic plugin or model-callable loader is delivered. Later progressive-disclosure consumers own their actual protocol.

Decision sources: [CG06-Q15](../../design/contract/sl-03-m2-grill.md#cg06-q15), [CG06-Q17](../../design/contract/sl-03-m2-grill.md#cg06-q17), [CG06-Q45](../../design/contract/sl-03-m2-grill.md#cg06-q45), [CG06-Q46](../../design/contract/sl-03-m2-grill.md#cg06-q46), [CG06-Q191](../../design/contract/sl-03-m2-grill.md#cg06-q191), [CG06-Q192](../../design/contract/sl-03-m2-grill.md#cg06-q192).

<a id="ctx-008"></a>
**CTX-008.** **Exact source admission.** Preparation resolves exact typed references and required local permission/revision predicates. Initial publication and later Frame/Tool boundaries MUST atomically recheck the local mutable authorities they can verify; no external I/O belongs in the SQLite transaction. Controlled static capability/configuration is not permission by itself. Required unavailable exact data MUST NOT be replaced by latest, guessed, fetched externally or silently omitted. Protected EAGER_EXACT content MUST be included completely under the admitted projection; no lossy summary or automatic model change. The exercise permits only its exact declared historical response target. A model-generated alternative identity grants no access.

<a id="ctx-009"></a>
**CTX-009.** **Scope and revocation.** Initial Package capability scope is a ceiling for the Run. Each Frame's visible tools/data intersect registration, Skill policy, Package scope and current permission. Reallowing within that scope does not expand it or reopen an ended task. Legitimate lazy exact resolution or same-task admitted committed versions follow their source-owned agreement; later unrelated edits do not silently change the task. Revocation of protected EAGER_EXACT input ends the frozen task and blocks later model/Tool reuse/current-result publication. Historical Package/Frame reading for lawful storage/audit/recovery remains separate from permission to send content again; revocation does not erase prior transmission facts.

Decision sources: [CG06-Q10](../../design/contract/sl-03-m2-grill.md#cg06-q10), [CG06-Q47](../../design/contract/sl-03-m2-grill.md#cg06-q47), [CG06-Q59](../../design/contract/sl-03-m2-grill.md#cg06-q59), [CG06-Q64](../../design/contract/sl-03-m2-grill.md#cg06-q64), [CG06-Q135](../../design/contract/sl-03-m2-grill.md#cg06-q135), [CG06-Q205](../../design/contract/sl-03-m2-grill.md#cg06-q205).

<a id="ctx-010"></a>
**CTX-010.** **Capacity admission.** Every executable model profile MUST provide an applicable estimator/capacity method, context limit, effective output cap and nonnegative safety margin. Persist the immutable evaluation basis for each admitted Frame: estimator_key, estimated_input_tokens, context_limit, output_token_cap, context_margin and exact frame hash/length association. All token quantities are exact finite integers, limits positive and estimates/margins nonnegative. Admit only when estimated_input_tokens + output_token_cap + context_margin fits context_limit using checked arithmetic. Include instructions, Tool schemas and protocol overhead under the estimator's documented applicability. The same effective output cap MUST govern Context, reservation and Provider request; no hidden SDK default. Estimation is not a Provider-guaranteed upper bound.

Decision sources: [CG06-Q49](../../design/contract/sl-03-m2-grill.md#cg06-q49), [CG06-Q53](../../design/contract/sl-03-m2-grill.md#cg06-q53), [CG06-Q54](../../design/contract/sl-03-m2-grill.md#cg06-q54), [CG06-Q55](../../design/contract/sl-03-m2-grill.md#cg06-q55), [CG06-Q140](../../design/contract/sl-03-m2-grill.md#cg06-q140).

<a id="ctx-011"></a>
**CTX-011.** **Shared estimate, separate policy.** Context and Budget MUST share this one immutable estimator evaluation for the actual Frame. Budget applies its own frozen reservation/pricing assumptions; Context keeps its own capacity margin. Do not estimate the same Frame independently with unexplained different token counts or merge both owners into a universal admission policy. Candidate evaluations may be computed before publication, but the atomic boundary MUST verify their exact Frame/configuration association.

Decision sources: [CG06-Q68](../../design/contract/sl-03-m2-grill.md#cg06-q68), [CG06-Q83](../../design/contract/sl-03-m2-grill.md#cg06-q83), [CG06-Q85](../../design/contract/sl-03-m2-grill.md#cg06-q85), [CG06-Q118](../../design/contract/sl-03-m2-grill.md#cg06-q118), [CG06-Q140](../../design/contract/sl-03-m2-grill.md#cg06-q140), [CG06-Q175](../../design/contract/sl-03-m2-grill.md#cg06-q175).

<a id="ctx-012"></a>
**CTX-012.** **Technical bounds and denials.** Require finite controlled package/frame/input structural bounds, including max_frame_bytes, before enabling a profile. Reject over-limit/unsupported/invalid candidates with precise PACKAGE_TOO_LARGE, FRAME_TOO_LARGE, CONTEXT_CAPACITY_EXCEEDED, CONTEXT_CONFIGURATION_UNAVAILABLE or CONTEXT_INPUT_REJECTED causes as applicable. These are operation rejections, not generic business failures. Do not dispatch experimentally to discover whether protected inputs fit. A local candidate calculation failure does not damage a healthy Budget ledger. Per-Skill business sizes remain consumer-owned; no universal text-count policy is imposed.

Decision sources: [CG06-Q39](../../design/contract/sl-03-m2-grill.md#cg06-q39), [CG06-Q49](../../design/contract/sl-03-m2-grill.md#cg06-q49), [CG06-Q55](../../design/contract/sl-03-m2-grill.md#cg06-q55), [CG06-Q99](../../design/contract/sl-03-m2-grill.md#cg06-q99), [CG06-Q183](../../design/contract/sl-03-m2-grill.md#cg06-q183), [CG06-Q200](../../design/contract/sl-03-m2-grill.md#cg06-q200).

<a id="ctx-013"></a>
**CTX-013.** **Historical raw reads.** read_context_package(run_id) and read_context_frame(invocation_id) are internal read operations. Validate historical read access, retained associations and actual stored length/hash. Return the record's actual bytes/metadata without requiring an enabled Skill or decoder; interpretation separately requires the exact format reader. Distinguish RUN_NOT_FOUND/INVOCATION_NOT_FOUND, nonsemantic NO_PACKAGE, INVOCATION_KIND_MISMATCH, FRAME_NOT_PUBLISHED, CONTEXT_PAYLOAD_UNAVAILABLE, CONTEXT_INTEGRITY_FAILED, CONTEXT_FORMAT_UNAVAILABLE and STORAGE_UNAVAILABLE. For semantic MODEL, proven PREPARED/no intent permits FRAME_NOT_PUBLISHED; committed intent makes its Frame mandatory. Missing/corrupt committed content cannot be reconstructed as history. A read neither repairs nor ends a Run.

<a id="ctx-014"></a>
**CTX-014.** **Retention and historical interpretation.** Retain initial Packages and every committed Frame for OPEN and ENDED Runs; M2 introduces no purge/TTL/Pin subsystem. Exact historical configuration/reader availability is separate from current execution enablement: never autoload old code, enable a disabled capability or reinterpret content under current defaults. Missing required interpretation yields unavailability, not fabricated conflict or replacement evidence. Source body retention follows actual recovery dependencies rather than pinning all lineage forever. Storage owns durable integrity and conditional recovery access.

<a id="ctx-015"></a>
**CTX-015.** **Result inclusion.** Only lawfully durable complete model responses and action-owned admitted Tool result evidence may support subsequent input. Tool results are read by exact TOOL Invocation/result reference, not a caller-provided string claiming completion. Apply current content admission independently of action outcome. Allowed projection/redaction is recorded by CTX-006; rejection cannot erase known action completion. Preserve assistant Tool-call/result associations and necessary reasoning. A partial stream is never a recoverable complete conversation turn.
