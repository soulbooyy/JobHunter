# Budget Contract — Foreground Invocation Resources

> Normative scope revision: **2026-09-24.S3M2-r1**. English is authoritative. This defines required behavior, not implemented or executed acceptance. Earlier scoped consumers remain unchanged.

[Decision register](../../design/contract/sl-03-m2-grill.md) · [Contract index](../index.md)

This internal foreground scope consumes COM-049 and the existing Workspace/Runtime transaction and authority protocols. ExecutionBudget is resource accounting, not business-result authority.

<a id="bud-001"></a>
**BUD-001.** **Owner and dimensions.** Foreground Application owns a stable operation_id UUIDv4 and its immutable allocation; Runtime treats the ID as opaque within the Workspace. It is not an AgentRun, business aggregate or universal Operation lifecycle. Multiple Runs may share the allocation. M2 supports MODEL_CALLS, TOTAL_TOKENS and optional CNY monetary accounting only, not shared Tool-count/step quotas, FX, top-up, transfer or renewal. Skill defines semantic allowances; Budget alone accounts for these resources. Money is not required for every Operation and no Run-local monetary cap exists.

Decision sources: [CG06-Q3](../../design/contract/sl-03-m2-grill.md#cg06-q3), [CG06-Q38](../../design/contract/sl-03-m2-grill.md#cg06-q38), [CG06-Q66](../../design/contract/sl-03-m2-grill.md#cg06-q66), [CG06-Q67](../../design/contract/sl-03-m2-grill.md#cg06-q67), [CG06-Q79](../../design/contract/sl-03-m2-grill.md#cg06-q79), [CG06-Q81](../../design/contract/sl-03-m2-grill.md#cg06-q81), [CG06-Q116](../../design/contract/sl-03-m2-grill.md#cg06-q116), [CG06-Q163](../../design/contract/sl-03-m2-grill.md#cg06-q163), [CG06-Q164](../../design/contract/sl-03-m2-grill.md#cg06-q164), [CG06-Q186](../../design/contract/sl-03-m2-grill.md#cg06-q186).

<a id="bud-002"></a>
**BUD-002.** **Exact quantities and money.** MODEL counts/token quotas and counters are exact integers 0..9223372036854775807, never Boolean/string-coerced values. Monetary allocation/reservation/debit is a nonnegative exact integer number of 10^-8 CNY units in the same range: external fixed-eight-place plain decimal strings 0.00000000..92233720368.54775807. No signs/exponents/commas/float rounding are admitted. Zero enables zero allowance; null disables only explicitly nullable allocation dimensions. Every sum/subtraction/product conversion must check its supported range, with no wrap/saturation/clipping. Raw usage, price rates and exact pre-quantization calculated cost retain their own exact meaning; they are not rounded to ledger precision.

Decision sources: [CG06-Q67](../../design/contract/sl-03-m2-grill.md#cg06-q67), [CG06-Q117](../../design/contract/sl-03-m2-grill.md#cg06-q117), [CG06-Q118](../../design/contract/sl-03-m2-grill.md#cg06-q118), [CG06-Q121](../../design/contract/sl-03-m2-grill.md#cg06-q121), [CG06-Q122](../../design/contract/sl-03-m2-grill.md#cg06-q122), [CG06-Q168](../../design/contract/sl-03-m2-grill.md#cg06-q168), [CG06-Q172](../../design/contract/sl-03-m2-grill.md#cg06-q172), [CG06-Q182](../../design/contract/sl-03-m2-grill.md#cg06-q182).

<a id="bud-003"></a>
**BUD-003.** **Complete foreground allocation.** ForegroundBudgetAllocation:v1 has exactly model_call_limit (integer or null), total_token_limit (integer or null), monetary (null or exactly currency=CNY and limit, the BUD-002 string). At least one dimension MUST be enabled. This complete nullable shape is scoped to current foreground allocation, not all future background/Eval owners. Retain the format key and original admitted allocation semantics; current configuration changes MUST NOT alter historical comparison or reset funds. This needs no BudgetStartReceipt or independent allocation fingerprint entity.

Decision sources: [CG06-Q119](../../design/contract/sl-03-m2-grill.md#cg06-q119), [CG06-Q121](../../design/contract/sl-03-m2-grill.md#cg06-q121), [CG06-Q122](../../design/contract/sl-03-m2-grill.md#cg06-q122), [CG06-Q123](../../design/contract/sl-03-m2-grill.md#cg06-q123), [CG06-Q170](../../design/contract/sl-03-m2-grill.md#cg06-q170), [CG06-Q171](../../design/contract/sl-03-m2-grill.md#cg06-q171).

<a id="bud-004"></a>
**BUD-004.** **Ensure scope.** ensure_foreground_budget(operation_id, original_allocation) is an internal idempotent operation. Under Workspace access/structural checks, atomically create an absent valid scope, return its consistent read view for the same original allocation, or return BUDGET_ALLOCATION_CONFLICT for a different one. Confirmation does not replenish accounting. Retain the caller's original identity/allocation during uncertain commit; prove actual committed state within finite arbitration bounds before claiming success/absence. A semantic-start with no established owner yields BUDGET_OWNER_NOT_FOUND. Missing mandatory ownership/accounting for an already committed Run is an integrity fault, not an invitation to create default funds.

Decision sources: [CG06-Q38](../../design/contract/sl-03-m2-grill.md#cg06-q38), [CG06-Q116](../../design/contract/sl-03-m2-grill.md#cg06-q116), [CG06-Q119](../../design/contract/sl-03-m2-grill.md#cg06-q119), [CG06-Q123](../../design/contract/sl-03-m2-grill.md#cg06-q123), [CG06-Q124](../../design/contract/sl-03-m2-grill.md#cg06-q124), [CG06-Q173](../../design/contract/sl-03-m2-grill.md#cg06-q173), [CG06-Q174](../../design/contract/sl-03-m2-grill.md#cg06-q174).

<a id="bud-005"></a>
**BUD-005.** **Run-local ceilings.** Each M2 semantic Run freezes required finite model_call_limit, total_token_limit and its existing deadline with the initial binding. Counts use BUD-002; the deadline is EXR's one deadline_at, not a second time authority. No per-Run monetary field is introduced. A Run's ceilings may exceed the Operation allocation and MUST NOT be clamped or rejected solely for that comparison. They are ceilings, not upfront subwallet allocations or promises of capacity. Every actual admission intersects both scopes and the Skill's semantic permission.

Decision sources: [CG06-Q7](../../design/contract/sl-03-m2-grill.md#cg06-q7), [CG06-Q37](../../design/contract/sl-03-m2-grill.md#cg06-q37), [CG06-Q162](../../design/contract/sl-03-m2-grill.md#cg06-q162), [CG06-Q164](../../design/contract/sl-03-m2-grill.md#cg06-q164), [CG06-Q172](../../design/contract/sl-03-m2-grill.md#cg06-q172), [CG06-Q186](../../design/contract/sl-03-m2-grill.md#cg06-q186), [CG06-Q187](../../design/contract/sl-03-m2-grill.md#cg06-q187), [CG06-Q201](../../design/contract/sl-03-m2-grill.md#cg06-q201).

<a id="bud-006"></a>
**BUD-006.** **Immutable ownership and records.** Budget derives an Invocation's Run/Operation from the committed semantic binding, never from caller override. The retained logical allocation record has operation_id, allocation_format_key and original_allocation. The Run binding has run_id, operation_id and its frozen local call/token limits. Logical reservation identity is invocation_id; no reservation UUID or request receipt is needed. Retain the original occupied resource components, exact Frame/estimator/cap/configuration and pricing bases, and associated settlement/release facts. Physical rows may differ, but mandatory owner and evidence associations must remain reconstructible and enforced.

Decision sources: [CG06-Q5](../../design/contract/sl-03-m2-grill.md#cg06-q5), [CG06-Q71](../../design/contract/sl-03-m2-grill.md#cg06-q71), [CG06-Q120](../../design/contract/sl-03-m2-grill.md#cg06-q120), [CG06-Q125](../../design/contract/sl-03-m2-grill.md#cg06-q125), [CG06-Q162](../../design/contract/sl-03-m2-grill.md#cg06-q162), [CG06-Q174](../../design/contract/sl-03-m2-grill.md#cg06-q174).

<a id="bud-007"></a>
**BUD-007.** **Reservation calculation.** Budget calculates from the actual immutable Frame estimator basis N, effective output cap O and the selected bounded reservation assumptions. The selected protocol MUST define its deterministic reservation calculation and retain enough immutable basis to reproduce it; arbitrary caller reserve amounts are rejected. The first DeepSeek profile occupies one MODEL call, reserves input/output tokens using N and O with any explicitly declared conservative Budget margin, and estimates money using cache-miss input and permitted output rates. The exact margin/price-band assumptions must be explicit, finite and frozen; Context margin is not silently reused or a second estimate. Verify all associations and availability at EXR's atomic boundary. No reservation is acquired merely during candidate preparation.

Decision sources: [CG06-Q49](../../design/contract/sl-03-m2-grill.md#cg06-q49), [CG06-Q53](../../design/contract/sl-03-m2-grill.md#cg06-q53), [CG06-Q54](../../design/contract/sl-03-m2-grill.md#cg06-q54), [CG06-Q68](../../design/contract/sl-03-m2-grill.md#cg06-q68), [CG06-Q69](../../design/contract/sl-03-m2-grill.md#cg06-q69), [CG06-Q83](../../design/contract/sl-03-m2-grill.md#cg06-q83), [CG06-Q85](../../design/contract/sl-03-m2-grill.md#cg06-q85), [CG06-Q118](../../design/contract/sl-03-m2-grill.md#cg06-q118), [CG06-Q140](../../design/contract/sl-03-m2-grill.md#cg06-q140), [CG06-Q175](../../design/contract/sl-03-m2-grill.md#cg06-q175).

<a id="bud-008"></a>
**BUD-008.** **Immutable price basis.** Monetary admission requires an exact controlled CNY price basis covering the selected model/mode/context band: input cache-hit, input cache-miss and output rates in CNY per 1,000,000 tokens. Rates are finite nonnegative exact decimals, not binary floats; exact snapshots or immutable configuration references must preserve their historical interpretation. This is not a PriceRule lifecycle/catalog or live billing/FX service. Configuration changes cannot reprice an existing reservation/settlement. Use an explicitly conservative applicable band for reservation when necessary; do not promise an invoice-equivalent amount. Missing applicable pricing blocks monetary admission only, not an otherwise supported money-disabled scope.

Decision sources: [CG06-Q67](../../design/contract/sl-03-m2-grill.md#cg06-q67), [CG06-Q68](../../design/contract/sl-03-m2-grill.md#cg06-q68), [CG06-Q79](../../design/contract/sl-03-m2-grill.md#cg06-q79), [CG06-Q81](../../design/contract/sl-03-m2-grill.md#cg06-q81), [CG06-Q82](../../design/contract/sl-03-m2-grill.md#cg06-q82), [CG06-Q83](../../design/contract/sl-03-m2-grill.md#cg06-q83), [CG06-Q85](../../design/contract/sl-03-m2-grill.md#cg06-q85), [CG06-Q86](../../design/contract/sl-03-m2-grill.md#cg06-q86), [CG06-Q169](../../design/contract/sl-03-m2-grill.md#cg06-q169).

<a id="bud-009"></a>
**BUD-009.** **Call occupancy.** Occupy a call in the same transaction as dispatch intent, not after the response. Every actual or possibly sent request retains consumption/exposure even when output validation fails, a response is lost, or execution times out. Only BUD-017's proven no-send release can return that occupancy. Retained response/usage history is distinct from the Run's active serial position; unsettled accounting does not by itself keep completed execution active.

Decision sources: [CG06-Q69](../../design/contract/sl-03-m2-grill.md#cg06-q69), [CG06-Q72](../../design/contract/sl-03-m2-grill.md#cg06-q72), [CG06-Q75](../../design/contract/sl-03-m2-grill.md#cg06-q75), [CG06-Q76](../../design/contract/sl-03-m2-grill.md#cg06-q76), [CG06-Q78](../../design/contract/sl-03-m2-grill.md#cg06-q78), [CG06-Q180](../../design/contract/sl-03-m2-grill.md#cg06-q180).

<a id="bud-010"></a>
**BUD-010.** **Token semantics.** TOTAL_TOKENS means complete trustworthy input plus output totals, not a discounted cache count. Cache-hit and cache-miss are partitions of input; reasoning tokens are included within applicable output, not an additional debit. Do not build M2 input/output subledgers. Partial input facts may be retained but cannot release the full token reservation as if a final total were known. The DeepSeek adapter must validate field types/relationships under its controlled protocol; unsupported/out-of-range/inconsistent components stay untrusted rather than coerced to zero.

Decision sources: [CG06-Q74](../../design/contract/sl-03-m2-grill.md#cg06-q74), [CG06-Q84](../../design/contract/sl-03-m2-grill.md#cg06-q84), [CG06-Q87](../../design/contract/sl-03-m2-grill.md#cg06-q87), [CG06-Q90](../../design/contract/sl-03-m2-grill.md#cg06-q90), [CG06-Q168](../../design/contract/sl-03-m2-grill.md#cg06-q168), [CG06-Q185](../../design/contract/sl-03-m2-grill.md#cg06-q185).

<a id="bud-011"></a>
**BUD-011.** **Cost and quantization.** For trustworthy components sufficient to determine cost under the frozen basis, exact calculated budget cost is (input_hit * hit_rate + input_miss * miss_rate + output_total * output_rate) / 1000000, with the selected basis's explicit applicable band. Cache/reasoning is not double counted. Sum exactly, then ceil once to 10^-8 CNY for the ledger debit. Reservations may use the same conservative upward quantization. Retain the pre-quantization value and basis; ledger rounding never modifies Provider tokens or raw rates. If missing components prevent a determinate cost, keep monetary exposure unresolved rather than settle using assumed cache hits/misses. This is internal budget accounting, not asserted Provider invoice cost.

Decision sources: [CG06-Q86](../../design/contract/sl-03-m2-grill.md#cg06-q86), [CG06-Q87](../../design/contract/sl-03-m2-grill.md#cg06-q87), [CG06-Q90](../../design/contract/sl-03-m2-grill.md#cg06-q90), [CG06-Q117](../../design/contract/sl-03-m2-grill.md#cg06-q117), [CG06-Q118](../../design/contract/sl-03-m2-grill.md#cg06-q118), [CG06-Q121](../../design/contract/sl-03-m2-grill.md#cg06-q121), [CG06-Q169](../../design/contract/sl-03-m2-grill.md#cg06-q169), [CG06-Q182](../../design/contract/sl-03-m2-grill.md#cg06-q182).

<a id="bud-012"></a>
**BUD-012.** **Atomic competition.** Within one short transaction, validate applicable owner/Run ceilings and current counters, occupy call/token/money components, and publish the matching Frame, descriptor, intent and dispatch_generation. Contenders cannot both spend the same balance. No network access occurs inside this transaction. Failed atomic admission publishes none of those new facts. Confirmation of the same committed publication does not reserve again; verify the original associations while allowing lawful later settlement evolution. Detected partial/mismatched mandatory associations are integrity faults, not missing defaults.

Decision sources: [CG06-Q5](../../design/contract/sl-03-m2-grill.md#cg06-q5), [CG06-Q66](../../design/contract/sl-03-m2-grill.md#cg06-q66), [CG06-Q69](../../design/contract/sl-03-m2-grill.md#cg06-q69), [CG06-Q71](../../design/contract/sl-03-m2-grill.md#cg06-q71), [CG06-Q126](../../design/contract/sl-03-m2-grill.md#cg06-q126), [CG06-Q175](../../design/contract/sl-03-m2-grill.md#cg06-q175), [CG06-Q203](../../design/contract/sl-03-m2-grill.md#cg06-q203).

<a id="bud-013"></a>
**BUD-013.** **Evidence admission.** Accept absolute Invocation-associated usage facts only through admitted protocols: validated controlled adapter metering, explicitly labeled local estimates for their permitted uses, or a separately reviewed future reconciliation source. Model prose, Tool text, traces or Langfuse inferred prices cannot certify usage. Provider observations and usage live outside immutable response equality. Capture validated usage with first response publication when possible, but response success does not depend on settlement and identical-response read-only confirmation cannot mutate usage. Trusted usage may be retained/settled despite fenced/failed/oversized response publication, with exact dispatch association; no final usage is inferred from arbitrary partial fragments.

Decision sources: [CG06-Q70](../../design/contract/sl-03-m2-grill.md#cg06-q70), [CG06-Q74](../../design/contract/sl-03-m2-grill.md#cg06-q74), [CG06-Q77](../../design/contract/sl-03-m2-grill.md#cg06-q77), [CG06-Q104](../../design/contract/sl-03-m2-grill.md#cg06-q104), [CG06-Q111](../../design/contract/sl-03-m2-grill.md#cg06-q111), [CG06-Q115](../../design/contract/sl-03-m2-grill.md#cg06-q115), [CG06-Q168](../../design/contract/sl-03-m2-grill.md#cg06-q168), [CG06-Q184](../../design/contract/sl-03-m2-grill.md#cg06-q184), [CG06-Q210](../../design/contract/sl-03-m2-grill.md#cg06-q210).

<a id="bud-014"></a>
**BUD-014.** **Unknown and estimated components.** Preserve known, estimated and unknown meanings per actual component and resource dimension. Missing values are not zero. An estimate may support capacity/reservation/explanation but cannot finalize unknown token/CNY consumption or release its unresolved reservation in M2. Complete response, ended Run, cancellation or elapsed time is not settlement proof. Different resource dimensions may converge independently when their evidence is sufficient; retain the remainder's original conservative occupancy.

Decision sources: [CG06-Q73](../../design/contract/sl-03-m2-grill.md#cg06-q73), [CG06-Q74](../../design/contract/sl-03-m2-grill.md#cg06-q74), [CG06-Q76](../../design/contract/sl-03-m2-grill.md#cg06-q76), [CG06-Q83](../../design/contract/sl-03-m2-grill.md#cg06-q83), [CG06-Q104](../../design/contract/sl-03-m2-grill.md#cg06-q104), [CG06-Q165](../../design/contract/sl-03-m2-grill.md#cg06-q165), [CG06-Q185](../../design/contract/sl-03-m2-grill.md#cg06-q185), [CG06-Q208](../../design/contract/sl-03-m2-grill.md#cg06-q208).

<a id="bud-015"></a>
**BUD-015.** **Idempotent settlement.** reconcile_invocation_usage(invocation_id, admitted_absolute_evidence) derives owner and immutable basis, validates the evidence association, and atomically publishes legitimate debit/counter/reservation changes. Repeated identical facts confirm without another charge; previously unknown components may become known. Conflicting trusted known facts return USAGE_EVIDENCE_CONFLICT and must not overwrite prior truth. Caller additive/subtractive deltas are forbidden. Compare overlapping nonnull trustworthy component values under the same evidence_format_key and dispatch association; null never deletes a known value. Revalidate relationships against the merged known facts before mutation. Successful reconciliation returns {invocation_id, evidence_format_key, admitted_components, settled_dimensions, unresolved_dimensions, blocked_dimensions}: admitted_components uses BUD-025's six fields with nulls retained, and the three dimension lists contain unique applicable MODEL_CALLS/TOTAL_TOKENS/MONETARY values in that order. This is a read projection of canonical accounting at confirmation time, not an immutable receipt; unchanged evidence never charges again. One component's success does not imply others settled. An uncertain settlement acknowledgement requires confirming committed accounting, not charging again or reporting success without evidence.

Decision sources: [CG06-Q71](../../design/contract/sl-03-m2-grill.md#cg06-q71), [CG06-Q73](../../design/contract/sl-03-m2-grill.md#cg06-q73), [CG06-Q80](../../design/contract/sl-03-m2-grill.md#cg06-q80), [CG06-Q115](../../design/contract/sl-03-m2-grill.md#cg06-q115), [CG06-Q126](../../design/contract/sl-03-m2-grill.md#cg06-q126), [CG06-Q159](../../design/contract/sl-03-m2-grill.md#cg06-q159), [CG06-Q184](../../design/contract/sl-03-m2-grill.md#cg06-q184).

<a id="bud-016"></a>
**BUD-016.** **Late reconciliation.** Lawful accounting reconciliation may occur after Run ending without reopening it, creating a durable response, publishing a stale business result or making a Provider request to discover cost. Settlement cannot depend on trace export; earlier Trial/evaluator evidence is not rewritten. Re-evaluation may explicitly consume newly retained evidence as a new attempt. A valid consumer result does not require fully settled expense when its own completion authority is satisfied.

Decision sources: [CG06-Q70](../../design/contract/sl-03-m2-grill.md#cg06-q70), [CG06-Q73](../../design/contract/sl-03-m2-grill.md#cg06-q73), [CG06-Q111](../../design/contract/sl-03-m2-grill.md#cg06-q111), [CG06-Q115](../../design/contract/sl-03-m2-grill.md#cg06-q115), [CG06-Q159](../../design/contract/sl-03-m2-grill.md#cg06-q159), [CG06-Q167](../../design/contract/sl-03-m2-grill.md#cg06-q167), [CG06-Q210](../../design/contract/sl-03-m2-grill.md#cg06-q210), [CG06-Q216](../../design/contract/sl-03-m2-grill.md#cg06-q216).

<a id="bud-017"></a>
**BUD-017.** **Safe no-send release.** Release undispatched occupancy only with reliable evidence that adapter entry into the sending boundary did not occur and fencing that prevents the original path from entering later. Perform coherent release/counter changes atomically. A restarted path cannot derive this proof from intent plus no response. Local timeout/cancel/socket failure alone proves neither no remote work nor zero cost. Releasing local concurrency capacity is separate from releasing accounting exposure.

Decision sources: [CG06-Q72](../../design/contract/sl-03-m2-grill.md#cg06-q72), [CG06-Q76](../../design/contract/sl-03-m2-grill.md#cg06-q76), [CG06-Q78](../../design/contract/sl-03-m2-grill.md#cg06-q78), [CG06-Q127](../../design/contract/sl-03-m2-grill.md#cg06-q127), [CG06-Q131](../../design/contract/sl-03-m2-grill.md#cg06-q131), [CG06-Q132](../../design/contract/sl-03-m2-grill.md#cg06-q132).

<a id="bud-018"></a>
**BUD-018.** **Unknown exposure retention.** Preserve unresolved occupancy across process restart and Run completion. No TTL, terminal-status sweep, unobserved response, trace absence or estimated final charge releases it. Retain explanatory Invocation/resource association so monetary unknown for one request can coexist with settled tokens for another. This does not create a Universal Exposure entity or an implicit remote billing collector.

<a id="bud-019"></a>
**BUD-019.** **Overrun.** Truthful trustworthy usage beyond reservation/allocation must remain visible. Do not clip usage, enlarge allocation, refill a Run or erase previously committed business outcomes. Subsequent admission uses the actual settled and outstanding values, including overrun. Reservation is protection against known oversubscription, not proof of a Provider-guaranteed final charge cap.

Decision sources: [CG06-Q75](../../design/contract/sl-03-m2-grill.md#cg06-q75), [CG06-Q118](../../design/contract/sl-03-m2-grill.md#cg06-q118), [CG06-Q172](../../design/contract/sl-03-m2-grill.md#cg06-q172), [CG06-Q182](../../design/contract/sl-03-m2-grill.md#cg06-q182).

<a id="bud-020"></a>
**BUD-020.** **Arithmetic obstruction.** Check every configured quantity and cumulative accounting update. An invalid/unrepresentable uncommitted candidate rejects without Frame/intent/reservation and does not poison healthy accounting. If real trusted usage cannot be accumulated in the supported range, retain available raw evidence plus recoverable obstruction associated with affected owner/Run/dimension/Invocation; preserve unresolved occupancy and refuse unsafe admission for that component. No wrap, saturation, clipping, arbitrary-precision counter fallback or invented balance. Restart cannot forget the obstruction. Independent healthy owners need not fail; M2 adds no freely callable reset/unblock lifecycle.

Decision sources: [CG06-Q172](../../design/contract/sl-03-m2-grill.md#cg06-q172), [CG06-Q181](../../design/contract/sl-03-m2-grill.md#cg06-q181), [CG06-Q182](../../design/contract/sl-03-m2-grill.md#cg06-q182), [CG06-Q183](../../design/contract/sl-03-m2-grill.md#cg06-q183).

<a id="bud-021"></a>
**BUD-021.** **Consistent read view.** read_foreground_budget(operation_id) returns the original allocation plus a consistent resource view. Each of the three fixed dimensions is DISABLED, ACCOUNTABLE or BLOCKED. DISABLED has no available quota; ACCOUNTABLE has exact settled, outstanding, derived available and overrun, plus Invocation-associated unresolved facts; BLOCKED preserves known facts and obstruction reason with unavailable numeric availability. Do not overload null/zero to confuse disabled with blocked or hide exposure in one Boolean. Under ACCOUNTABLE, available is max(0, limit - settled - outstanding), and overrun is max(0, settled + outstanding - limit), using checked exact arithmetic; arithmetic failure produces BLOCKED, not fabricated numbers. Numeric availability is reservation-based, not a guarantee about unknown actual final expense. Reads grant no dispatch permit.
